Darkfuscator Guide

Build profiles

Lean keeps output small. Normal adds decoy branches. Heavy adds decoy slots and the most handler variants — the same seed always produces the same build.

Anti-environment

Strict probes the environment (identity, services, data types, settings) and binds the unseal key to it. A tampered or simulated environment fails the audit before the payload decodes.

Loader

Full wraps the build in an encrypted chunk loader with runtime checks and a Heartbeat re-audit. Fast uses a plain loader. Off ships the bare build.

Execution locks

Bind a build to a place ID, a universe ID, or both. The check runs before the payload is decoded, so the build refuses to run anywhere else.

Require genuine client

Refuses to run outside a real Roblox client: fewer than three genuine service probes fail the audit. Use it for builds that must never run under a simulator.

Honest limits

Obfuscation raises the cost of reading code; it is not a security boundary. Determined analysis of client-side code can always eventually recover it.
