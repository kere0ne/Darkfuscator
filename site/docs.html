Darkfuscator API

Obfuscate Luau source from any language. Send code to the API with your key, get back a VM-protected build: variable renaming, string encryption, control-flow flattening, junk insertion, an encrypted chunked anti-tamper loader and a custom bytecode VM.

Overview

Every Darkfuscator account automatically gets a personal API key. Create one on the sign-up page, copy it from your dashboard, and you are ready to call the API. Keys are shown as dk_live_... and are tied to your account; usage is metered per key.

The API is served from Cloudflare's edge network, runs the same engine as the website, and never exposes the engine internals: only the obfuscated output travels back.

Quick start

One request is all it takes:

TERMINAL
curl -X POST https://darkfuscator.pages.dev/api/v1/obfuscate \
  -H "Authorization: Bearer dk_live_YOUR_KEY_HERE" \
  -H "Content-Type: application/json" \
  -d '{"source": "print(\u0027Hello World\u0027)"}'

A successful response looks like:

RESPONSE · 200
{
  "success": true,
  "requestId": "req_9f3ab2c17d40e518",
  "preset": "maximum",
  "bytes": 82491,
  "durationMs": 1420,
  "result": "-- obfuscated Luau source, executed with loadstring(...) ..."
}

Authentication

All obfuscation endpoints authenticate with your API key in the Authorization header, using the Bearer scheme:

REQUEST HEADER
Authorization: Bearer YOUR_API_KEY
  • Keys start with dk_live_ and are unique per account.
  • Your key is available any time on the dashboard; the old key stops working the moment you regenerate.
  • Never publish your key in client-side code, public repositories or screenshots. If a key leaks, regenerate it from the dashboard.
  • Sessions on the website itself use httpOnly cookies; your API key is never needed by the browser.
Treat your API key like a password. Requests with a missing, malformed or regenerated key return 401.

Base URL

BASE URL
https://darkfuscator.pages.dev

All endpoint paths in this document are relative to this base URL. The API supports cross-origin requests (CORS), so you can call it from browser-based apps and server code alike.

Obfuscate

POST/api/v1/obfuscate

Obfuscates Luau source and returns the protected build.

Request headers

HeaderValue
AuthorizationBearer YOUR_API_KEY (required)
Content-Typeapplication/json

Request body

FieldTypeDescription
sourcestringLuau source to protect. Required. Up to 200,000 characters.
presetstringlightweight, balanced or maximum. Defaults to maximum.
optionsobjectOptional per-option overrides, applied on top of the preset. See Options.
seednumberOptional deterministic seed (0 to 4294967295). The same source with the same seed produces the same output.
REQUEST
{
  "source": "local Players = game:GetService('Players')\nprint(Players.LocalPlayer.Name)",
  "preset": "maximum",
  "options": {
    "encryptStrings": true,
    "renameVariables": true
  }
}

Response

FieldTypeDescription
successbooleantrue when the build succeeded.
requestIdstringUnique id for this request, useful when contacting support.
presetstringThe preset that was applied.
bytesnumberSize of the protected output in bytes.
durationMsnumberEngine time in milliseconds.
resultstringThe obfuscated Luau source. Run it with loadstring/load.

Response headers always carry your current rate-limit state: X-RateLimit-Remaining-Minute and X-RateLimit-Remaining-Day.

Options & presets

Presets are complete option sets. The maximum preset (the default) enables every protection layer and cannot be weakened from the API: options can only add work, not remove protections already in the preset.

PresetProtection layersBest for
lightweightRenaming, string encryption, basic flatteningLarge scripts, faster builds
balancedRenaming, string encryption, control-flow flattening, moderate junkEveryday scripts
maximumEverything: full flattening, heavy junk, encrypted chunked anti-tamper loader, scrambled VM dispatch, silent environment auditingMaximum resistance to deobfuscation

Common option overrides (valid keys depend on the engine version; unknown keys are ignored):

OPTIONS EXAMPLE
{
  "options": {
    "renameVariables": true,
    "encryptStrings": true,
    "controlFlow": true,
    "junk": 2,
    "guard": 2,
    "antiTamper": 2,
    "nameStyle": "confuse"
  }
}

Errors

Error responses share one shape:

ERROR · 401
{
  "success": false,
  "error": {
    "code": "unauthorized",
    "message": "Invalid or revoked API key."
  }
}
StatusCodeMeaning
400bad_requestMissing or malformed fields; unparseable source.
401unauthorizedAPI key missing, invalid or regenerated.
413payload_too_largeSource over 200,000 characters or body over ~1 MB.
429rate_limitedRate limit hit. Respect Retry-After.
500engine_errorThe engine failed on this input.

Authentication is never read from the request body or query string, only from the Authorization header.

Rate limits

ScopeLimit
Per API key30 requests / minute
Per API key1,000 requests / day
Auth endpoints20 requests / minute per IP

When limited, the API returns 429 with a Retry-After header (seconds). Every response includes X-RateLimit-* headers so you can pace your client before hitting the limit.

Example: JavaScript

NODE.JS 18+ (fetch)
const res = await fetch('https://darkfuscator.pages.dev/api/v1/obfuscate', {
  method: 'POST',
  headers: {
    'Authorization': 'Bearer dk_live_YOUR_KEY_HERE',
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    source: "print('Hello from Darkfuscator')",
    preset: 'maximum'
  })
});

const data = await res.json();
if (!data.success) throw new Error(data.error.message);
console.log('protected build:', data.bytes, 'bytes');
await import('node:fs').then(fs => fs.writeFileSync('out.luau', data.result));

Example: Python

PYTHON 3 (requests)
import requests

API = "https://darkfuscator.pages.dev/api/v1/obfuscate"
KEY = "dk_live_YOUR_KEY_HERE"

resp = requests.post(
    API,
    headers={
        "Authorization": f"Bearer {KEY}",
        "Content-Type": "application/json",
    },
    json={"source": "print('Hello from Darkfuscator')", "preset": "maximum"},
    timeout=120,
)
resp.raise_for_status()
data = resp.json()

with open("out.luau", "w") as f:
    f.write(data["result"])
print(f"protected build: {data['bytes']} bytes in {data['durationMs']} ms")

Example: Lua

Calling the API from an executor or Roblox server with HttpService:

LUAU
local HttpService = game:GetService("HttpService")

local function obfuscate(source)
    local payload = HttpService:JSONEncode({
        source = source,
        preset = "maximum",
    })
    local ok, res = pcall(function()
        return HttpService:RequestAsync({
            Url = "https://darkfuscator.pages.dev/api/v1/obfuscate",
            Method = "POST",
            Headers = {
                ["Content-Type"] = "application/json",
                ["Authorization"] = "Bearer dk_live_YOUR_KEY_HERE",
            },
            Body = payload,
        })
    end)
    if not ok or not res.Success then
        error("Darkfuscator API request failed")
    end
    local data = HttpService:JSONDecode(res.Body)
    if not data.success then
        error("Darkfuscator API error: " .. tostring(data.error and data.error.message or data.error))
    end
    return data.result
end

local protected = obfuscate("print('Hello from Darkfuscator')")
print(("protected build: %d bytes"):format(#protected))
